1. Introduction and Single Purpose

EXtracty is a browser extension developed by Miroslaw_34 designed with a single, clear purpose: to allow users to extract, clean, structure, OCR, and export content from web pages directly within the browser side panel.

EXtracty is built on a Local-First, Zero-Tracking architecture. The extension does not operate any proprietary server, proxy, database, analytics endpoint, or telemetry system. Everything you extract remains on your local machine unless you explicitly choose to invoke optional AI features using your own API credentials.

3. Optional Bring-Your-Own-Key (BYOK) AI Integration

AI features (Clean, Summarize, Translate) are strictly optional and disabled by default. They require:

  • Separate Informed Consent: Users must explicitly accept the AI disclosure modal before entering an API key or triggering any AI action. Completing the onboarding tour does NOT grant AI consent.
  • Zero-Plaintext at Rest: Your API key is encrypted using Web Cryptography API AES-GCM 256-bit encryption with a randomly generated 96-bit IV. The encryption key is non-exportable and stored in a secure IndexedDB database, preventing plaintext key extraction from standard storage dumps.
  • Direct HTTPS Communication: EXtracty connects directly to the official endpoints:
    • Google Gemini: generativelanguage.googleapis.com (Google Privacy Policy)
    • OpenRouter: openrouter.ai (OpenRouter Privacy Policy)
  • Instant Revocation: You can revoke consent at any time from the Settings drawer. Revocation instantly wipes the crypto vault, erases all saved key ciphertext, and disables AI features without affecting your documents.

4. Chrome Permissions & Host Access Justification

EXtracty adheres to the principle of least privilege:

  • sidePanel: Renders the primary workspace adjacent to your browser tab so you can extract, edit, and organize content without switching tabs.
  • storage: Preserves user preferences and encrypted key material locally (local), and holds active draft blocks during your session (session).
  • scripting: Re-injects the packaged content script into supported open tabs following installation or extension updates, ensuring extraction features function reliably without remote code.
  • downloads: Saves user-requested exported files (.md, .txt, .csv, .docx, .pdf) to the local Downloads folder.
  • contextMenus: Offers quick-access extraction commands from Chrome's right-click context menu.
  • host_permissions (<all_urls>): Necessary because user extraction can occur on any webpage chosen by the user. The content script runs passively and never inspects or transmits page data until you trigger an explicit extraction tool. Chrome-protected pages (e.g. chrome://, Web Store) remain strictly inaccessible.

Note: The activeTab permission is not requested.

5. Remote Hosted Code Prohibition

In strict compliance with Manifest V3 policies, EXtracty contains NO remote hosted code. All scripts, HTML templates, CSS styles, and WebAssembly Tesseract OCR binaries are packaged directly within the extension archive. Dynamic code evaluation (such as eval() or remote script loaders) is prohibited by a strict Content Security Policy.

6. Third-Party Services

EXtracty interacts with external services only in the following user-directed scenarios:

  • Google Gemini / OpenRouter: Direct API calls when you explicitly trigger an AI feature using your own API key.
  • GitHub Pages: Hosts this public documentation and privacy portal (GitHub Privacy Statement).
  • PayPal: Optional external voluntary donation link (PayPal Privacy Statement).

7. User Rights & Data Deletion

Because all working data is stored locally on your device:

  • Clicking "Clear Document" immediately purges all current blocks, text drafts, and cached IndexedDB media.
  • Revoking AI consent immediately clears your encrypted key and crypto vault.
  • Uninstalling the extension from Chrome permanently deletes all local storage, session storage, and IndexedDB databases.

3. Funzionalità AI Facoltative (BYOK) e Consenso

Le funzioni AI (Pulizia avanzata, Riassunto, Traduzione) sono puramente facoltative e disattivate di default:

  • Consenso Informato Separato: Prima di salvare una chiave API o eseguire un'azione AI è obbligatorio esprimere un consenso esplicito e consapevole. Il completamento del tour introduttivo non equivale al consenso AI.
  • Nessun Testo in Chiaro a Riposo: La chiave API viene cifrata tramite Web Cryptography API nativa con algoritmo AES-GCM a 256 bit e IV casuale a 96 bit. La chiave crittografica è marcata come non-esportabile in un database IndexedDB isolato.
  • Comunicazione Diretta HTTPS: EXtracty si connette esclusivamente agli endpoint ufficiali:
    • Google Gemini: generativelanguage.googleapis.com (Informativa Privacy Google)
    • OpenRouter: openrouter.ai (Informativa Privacy OpenRouter)
  • Revoca Immediata: Nelle Impostazioni è presente il pulsante "Revoca consenso e cancella chiave" che distrugge istantaneamente il vault crittografico ed elimina ogni traccia della chiave salvata.

4. Permessi Chrome e Accesso alle Pagine

  • sidePanel: Permette di visualizzare l'area di lavoro a fianco della pagina web senza alterarne la struttura visiva.
  • storage: Memorizza localmente le preferenze e il materiale crittografico (local) e mantiene i blocchi di lavoro durante la sessione attiva (session).
  • scripting: Ripristina il content script sulle schede aperte dopo l'installazione o aggiornamento dell'estensione.
  • downloads: Consente di salvare i documenti esportati dall'utente nella cartella Download del computer.
  • contextMenus: Fornisce comandi di estrazione rapida dal menu contestuale del pulsante destro.
  • host_permissions (<all_urls>): Indispensabile per consentire all'utente di estrarre contenuti da qualsiasi sito web desiderato. Il content script non effettua alcuna lettura o analisi passiva prima che l'utente clicchi esplicitamente su un comando di estrazione. Le pagine protette di sistema (es. chrome://) sono inaccessibili per disegno di sicurezza di Chrome.

Nota: Il permesso activeTab non è presente.

5. Divieto Assoluto di Codice Remoto

In conformità al regolamento Manifest V3, EXtracty non contiene alcun codice remoto. Script, fogli di stile, template HTML e binari WASM di Tesseract sono inclusi integralmente nel pacchetto distribuito sul Chrome Web Store. La Content Security Policy impedisce l'esecuzione di codice caricato da server esterni o generato dinamicamente.

6. Servizi Terzi

EXtracty interagisce con servizi esterni solo nelle seguenti circostanze avviate dall'utente:

7. Diritti dell'Utente e Cancellazione dei Dati

  • Il pulsante "Svuota documento" cancella immediatamente tutti i blocchi, testi e media IndexedDB presenti nella sessione.
  • La revoca del consenso AI distrugge immediatamente la chiave cifrata e il vault di crittografia.
  • La disinstallazione dell'estensione dal browser rimuove definitivamente ogni dato memorizzato in local storage, session storage e IndexedDB.
