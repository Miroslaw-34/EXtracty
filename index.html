EXtracty Browser Extension

Smart, local-first web content extraction with offline OCR, session staging, multiple export formats, and optional privacy-centric Bring-Your-Own-Key AI.

Privacy Policy Support & Issues Tracker

🛡️ Local-First & Zero-Tracking Architecture

EXtracty has no proprietary backend servers, no analytics trackers, and no telemetry. All web page parsing, OCR recognition, and document assembly occur entirely inside your local browser sandbox.

⚡

Three Extraction Modes

Choose between Heuristic Auto-Extraction for whole articles, Point-and-Click Inspector for granular elements, or Area Box Selection for visual snapshots and OCR.

🔤

Offline Multilingual OCR

Optical Character Recognition is executed 100% client-side via bundled WebAssembly Tesseract. Additional languages download strictly as verified static data files.

🔐

Encrypted BYOK AI

Optional AI operations (Gemini / OpenRouter) require explicit prior informed consent. Your API keys are encrypted at rest with AES-GCM 256-bit and a non-exportable key stored locally by the extension.

💾

Flexible Export Formats

Export your assembled document instantly to Markdown (.md), Plain Text (.txt), CSV spreadsheet (.csv), Microsoft Word (.docx), or Adobe PDF (.pdf).
